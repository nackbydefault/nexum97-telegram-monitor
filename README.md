# NEXUM/97

Ideazione e progettazione: Giuseppe LISI

NEXUM/97 è un programma per Windows sviluppato in Rust. È un progetto **proprietario**: il codice
del programma, la sua documentazione operativa e la sua storia di sviluppo non sono pubblicati
e non sono distribuiti con questa repository.

Questa repository contiene soltanto le informazioni pubbliche sul progetto.

## Stato

In sviluppo. Nessuna versione è distribuita pubblicamente.

## Componenti open source

Alcuni componenti generici, senza funzioni di monitoraggio o di raccolta di dati, potranno essere
pubblicati in repository separate, ciascuna con la propria licenza. Quando succederà, saranno
elencati qui.

## Sicurezza

Le vulnerabilità si segnalano in privato: vedi [SECURITY.md](SECURITY.md).
