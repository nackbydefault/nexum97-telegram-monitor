# Sicurezza / Security

Ideazione e progettazione: Giuseppe LISI

Non segnalare le vulnerabilità in una issue pubblica. Usa la segnalazione privata di GitHub:
scheda **Security** → **Report a vulnerability**.

Non includere credenziali, dati personali, log non ripuliti o informazioni operative.

*English:* do not open a public issue for a vulnerability. Use GitHub private vulnerability
reporting (Security tab → Report a vulnerability). Do not include credentials, personal data,
uncleaned logs or operational details.
