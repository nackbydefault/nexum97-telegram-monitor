# Codice di condotta / Code of conduct

Ideazione e progettazione: Giuseppe LISI

Chi partecipa a questo progetto si comporta con rispetto: niente molestie, insulti, attacchi
personali o diffusione di dati personali altrui. Le segnalazioni di comportamenti scorretti si
inviano in privato al titolare tramite GitHub. Il titolare decide e può escludere chi viola queste
regole.

*English:* be respectful. No harassment, insults, personal attacks or publishing other people's
personal data. Report misconduct privately to the owner via GitHub; the owner decides and may
exclude anyone who breaks these rules.
